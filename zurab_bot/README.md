# Зураб

`@ZurabPorucheniyaBot` — owner-only помощник для Telegram-групп. Он хранит
сообщения локально в SQLite, собирает явные договорённости и ведёт список
поручений.

## Безопасная модель

- Бот не сохраняет сообщения группы, пока владелец не отправит `/enable`.
- Команды и естественные поручения принимает только от `ZURAB_OWNER_ID`.
- Произвольные внешние действия не исполняются: для них нужен отдельный
  подключённый исполнитель.
- Токен хранится только в игнорируемом Git файле `zurab_bot/.env`.

## Запуск

```bash
python -m venv .venv
.venv/bin/pip install -r zurab_bot/requirements.txt
cp zurab_bot/.env.example zurab_bot/.env
# Заполнить ZURAB_BOT_TOKEN и ZURAB_OWNER_ID
.venv/bin/python -m zurab_bot.bot
```

## Команды

- `/enable` — начать сохранять новые сообщения группы;
- `/disable` — прекратить сохранение;
- `/task текст` — записать поручение;
- `/tasks` — показать открытые поручения;
- `/done номер` — закрыть поручение;
- `/summary [число]` — собрать явные поручения из последних сообщений;
- `Зураб, напиши: текст` — отправить сообщение от имени бота.

После отключения privacy mode в BotFather бота нужно заново добавить в ранее
подключённые группы. Историю до момента добавления Telegram Bot API не отдаёт.
