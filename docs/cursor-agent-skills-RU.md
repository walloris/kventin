# Agent Skills в этом проекте

В репозитории используется набор **Agent Skills** от [addyosmani/agent-skills](https://github.com/addyosmani/agent-skills) — это не код, а **Markdown-инструкции** для ИИ-агента: пошаговые процессы, критерии проверки и «анти-отмазки», чтобы агент не пропускал тесты, ревью и дисциплину разработки.

## Где что лежит

| Путь | Назначение |
|------|------------|
| `vendor/agent-skills/` | Полная копия исходников пакета (остальные скиллы, `agents/`, `references/`, лицензия). Обновление: скачать свежий архив/клон с GitHub и заменить папку. |
| `.cursor/rules/*.md` | Небольшой **набор правил под Cursor**: эти файлы проект подхватывает как контекст для агента. |

Сейчас в `.cursor/rules/` скопированы скиллы:

- `using-agent-skills.md` — с чего начинать и как выбирать подходящий процесс.
- `incremental-implementation.md` — маленькие вертикальные срезы, проверка, коммиты.
- `test-driven-development.md` — TDD и доказательство тестами.
- `code-review-and-quality.md` — оси ревью и качество перед слиянием.
- `debugging-and-error-recovery.md` — воспроизведение, локализация, фикс, защита от регрессий.

## Как этим пользоваться в Cursor

1. **Обычный чат / Agent** — правила из `.cursor/rules/` уже участвуют в контексте (в пределах лимитов модели). Явно можно сказать: *«Следуй incremental-implementation и test-driven-development»*.
2. **Не грузить всё сразу** — если контекст раздуется, лишние `.md` из `.cursor/rules/` можно временно вынести в другое место или отключить правило в настройках Cursor для правил.
3. **Дополнительные скиллы** — нужный `SKILL.md` взять из `vendor/agent-skills/skills/<имя>/` и скопировать в `.cursor/rules/` под понятным именем (как в официальной [cursor-setup](https://github.com/addyosmani/agent-skills/blob/main/docs/cursor-setup.md)).
4. **Персоны ревью** — файлы в `vendor/agent-skills/agents/` (например `code-reviewer.md`) можно вставить в запрос: *«Проверь дифф по этому фреймворку»*.

## Важно

- Скиллы **дополняют**, а не отменяют ваши `.cursorrules` и пользовательские правила.
- У пакета лицензия **MIT**; полный текст — в `vendor/agent-skills/LICENSE`.
